Routing & Forwarding

How the simulated router makes a next-hop decision

Close this guide ×

1. Receive

A router receives a packet on an enabled interface. The forwarding engine checks the destination IPv4 address and decrements TTL.

2. Find candidate routes

The router considers connected networks and configured static routes that match the destination.

3. Longest-prefix match

The most specific matching prefix is selected. For example, /24 is preferred over /16 when both match. Metric and deterministic tie-breaking are used where applicable.

4. Resolve next hop

The selected next hop must be reachable through a connected interface and the physical/logical link path must be available.

5. Forward or fail

If a route and next hop are usable, the packet continues. If no route, interface, link, or neighbor path is available, the simulator records a failure event.
