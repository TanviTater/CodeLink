Architecture & Limitations

What the application does and does not simulate

Close this guide ×

Frontend

React + TypeScript + Vite. React Flow renders editable devices and links. The interface presents protocol walkthroughs, run results, diagnostics, packet details, challenge instructions and documentation.

Backend

FastAPI validates and stores project topologies, runs the deterministic simulation engine, and persists immutable run snapshots and result JSON in SQLite.

Simulation boundary

All networking is virtual. The app does not open raw sockets, contact external websites, resolve public DNS, or send real mail.

Routing

The engine models IPv4 forwarding, router route selection, TTL handling, link state and configured service/firewall checks. It is an educational abstraction rather than a full router operating system.

Known limitations

TCP retransmission timers, congestion control and full connection teardown are not implemented. Switch MAC learning and full ARP behavior are simplified. The challenge verifier is not challenge-specific. Browser-based end-to-end tests have not been verified in this generated package.

Academic use

Explain these boundaries in the project report and viva. A simulator should clearly distinguish implemented behavior from real-world protocol behavior.
