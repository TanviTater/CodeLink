IPv4 & Subnetting

Addressing concepts used by the simulator

Close this guide ×

IPv4 address

An IPv4 address identifies an interface, for example 192.168.10.10. Each interface address is paired with a CIDR prefix.

CIDR prefix

A /24 prefix means the first 24 bits identify the network. In dotted decimal this is 255.255.255.0. Devices with addresses in the same /24 are in the same IP subnet.

Default gateway

A host sends traffic for remote networks to its default gateway. The gateway address must be reachable on the host’s local subnet.

Common configuration error

If the PC is 192.168.10.10/24, its gateway should not be 10.0.0.1 because that address is not in its local subnet. Use the router LAN interface 192.168.10.1.

Multiple router interfaces

Each router interface belongs to a different connected network. The router forwards between networks using connected routes and configured static routes.
