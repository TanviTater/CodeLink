Understand the device types

PC is an endpoint; Switch connects devices in the same LAN; Router connects IP networks and uses routes; Server hosts simulated TCP/UDP services and DNS/HTTP/SMTP configuration.

Add devices

In Network Lab, click Add PC, Add Switch, Add Router, or Add Server. Drag each node to arrange the topology. Select a node to edit its properties in the right-hand panel.

Connect devices

Drag from a small connection handle on one node to a handle on another. A link line appears. Link connectivity is required for packet forwarding.

Configure IPv4

Set an address and prefix on every routed interface. For example, 192.168.10.10/24 means the host belongs to network 192.168.10.0/24. Set the PC gateway to the router interface in the same LAN, such as 192.168.10.1.

Configure routers

A router needs an interface in each connected subnet. Add static routes in the Static routes JSON field. Each route has network, prefix, nextHop, and metric. The next hop must be reachable through a connected interface.

Configure services

On a server, configure tcpPorts, udpPorts, dnsRecords, httpRoutes and acceptedRecipients. The sample server listens on TCP 80, 25 and 443, UDP 53 and 123, and has an A record for app.netsim.local.

Save and test

Save the project. Run ping first to test IP reachability. Then run TCP/HTTP/DNS/SMTP to test the relevant transport or application service.

Introduce a controlled fault

Disable a link using Toggle all links or set a device interface to Down. Save, run a test, and use Troubleshooting Lab to inspect the failure. Restore the setting and rerun.

Which device connects to which?

For a basic routed network, connect Client PC → Access Switch → Edge Router → Core Router → Application Server. PCs and servers normally use eth0. Switches use access ports p1, p2, p3 and so on. Routers use eth0 for the first link and eth1 for the second link. The link manager displays both ends of every connection and lets you enable or disable a cable.

Recommended build order

  1. Add a PC, a switch, a router and a server (or load the working sample).
  2. Connect the PC to the switch.
  3. Connect the switch to the router.
  4. Connect routers together using their second interfaces.
  5. Connect the final router to the server.
  6. Configure IP addresses, prefix lengths, default gateways and router routes.
  7. Save and run Ping first. Then try TCP or HTTP.
