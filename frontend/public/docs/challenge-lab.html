Challenge Lab Manual

How to complete and verify a guided lab

Close this guide ×

1. Open a challenge

Click any challenge card. The brief shows its objective and the fault description returned by the backend.

2. Understand the target

Translate the objective into a network check: interface state, IPv4/prefix, gateway, router route, link, firewall or server service.

3. Investigate

Open Network Lab and inspect the sample topology or your own saved project. Use ping and then a relevant transport/application protocol to narrow the fault.

4. Repair

Change the suspected setting. Avoid changing multiple unrelated values at once. Save the project after the repair.

5. Verify

Run a fresh successful simulation, return to the challenge card and click Verify latest run.

Scoring limitation

The present API verifier awards a basic pass when it finds a recent successful run for the project. It does not yet isolate a challenge topology, enforce the specific intended repair, or maintain a persistent per-challenge score. Treat the objective as a guided exercise rather than an anti-cheat assessment.
