Protocol Reference

Protocols available in this educational simulation

Close this guide ×

TCP

Models a three-way handshake using SYN, SYN-ACK and ACK, sequence/acknowledgement arithmetic, and closed-port reset behavior. It is not a full production TCP stack with congestion control, retransmission timers, or complete teardown.

ICMP ping

Simulates Echo Request and Echo Reply for reachability testing. Ping does not prove that a TCP application port is listening.

Traceroute

Uses TTL-limited probes to reveal forwarding hops. Results are simulated and depend on the implemented TTL and forwarding behavior.

UDP

Sends a connectionless datagram to a destination port. There is no TCP-style handshake or delivery guarantee.

DNS

Looks up configured A records in the simulated server’s DNS record map. No public DNS resolver is contacted.

HTTP

Simulates a GET request over the TCP path and reads the configured route/status from the server service map. No external website is contacted.

SMTP

Produces a simulated mail transaction transcript and checks the configured mail service/recipient policy. No real email is sent.
