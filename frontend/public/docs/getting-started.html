Getting Started

A first successful NetSim Studio session

Close this guide ×

1. Start both services

Keep the FastAPI backend running in one terminal and the Vite frontend in another. Open http://localhost:5173 in your browser.

2. Create or load a project

Choose New project, or open Network Lab and click Load sample topology. The sample contains a client PC, access switch, two routers, and an application server.

3. Save before simulating

Use Save project. Simulations run against the saved topology snapshot, not unsaved canvas edits.

4. Run a protocol

Open Protocol Simulator, choose a protocol card, step through its animation, and click Run against topology. The result contains status, events, packets, and diagnostics.

5. Inspect the result

Use Event timeline to follow forwarding, Packet details to inspect packet records, and Diagnostics to read evidence and suggested repairs.

6. Save your work

Projects and runs are stored in the local SQLite database. Export a project JSON from Network Lab to keep a portable copy.
